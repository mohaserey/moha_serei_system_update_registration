# moha_serei_system_update_registration
🇰🇭 Mohaserei System Update (MSN)

National Network Member Registration System

Mohaserei Network (MSN) is a web-based member registration system designed to organize and manage network members throughout Cambodia by province, district, commune, and participation category.

📌 Project Overview

The Mohaserei System Update (MSN) provides a structured registration interface for collecting member information, geographic locations, professional backgrounds, and participation resources.

The system aims to support a nationwide participation-based economic network through organized member registration.

💾 Data Storage

The current registration module uses browser localStorage.

Storage key:

mohaserey_members

Registered member information is stored locally in the browser.

Important: This implementation does not yet provide centralized database storage or cross-device synchronization. A backend database and authentication system are recommended for production deployment.
